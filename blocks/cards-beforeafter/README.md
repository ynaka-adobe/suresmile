# cards-beforeafter

Custom **cards** block. Purpose: before/after case results shown as a scrolling card carousel.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: before image | after image | text (H3 condition title, duration paragraph); the two images may share one cell (first = before, second = after).

## Supported variations

No variations.
